# 🗺️ SysMap — 시스템 지도 그리기

브라우저에서 바로 시스템 아키텍처 다이어그램은 물론, 강화·균형 루프가 있는
**인과 지도(causal loop diagram, 시스템 사고 지도)**까지 그릴 수 있는 온라인 도구입니다.
설치나 로그인 없이 정적 웹페이지만으로 동작하며, 그린 지도는 브라우저에 자동 저장되고
JSON/SVG/PNG 파일로 내보내거나 다시 불러올 수 있습니다.

## 사용해보기

- **로컬에서 열기**: `index.html`을 브라우저로 열면 바로 사용할 수 있습니다.
  (더블클릭으로 열거나, 정적 서버로 띄우려면 `python3 -m http.server` 등을 사용하세요.)
- **온라인으로 배포하기**: 이 저장소를 GitHub Pages로 배포하면 별도 서버 없이 URL 하나로
  누구나 접속해 지도를 그릴 수 있습니다. `.github/workflows/deploy.yml` 워크플로가 `main`
  브랜치에 푸시될 때마다 자동으로 GitHub Pages에 배포합니다.
  (저장소 Settings → Pages → Source를 "GitHub Actions"로 설정하면 활성화됩니다.)
- **브랜치 자동 PR·병합**: `.github/workflows/auto-pr-merge.yml` 워크플로가 `claude/*`
  브랜치에 푸시될 때마다 `main`으로 향하는 PR을 자동으로 만들거나(이미 열려 있으면 재사용)
  즉시 병합한 뒤 GitHub Pages 재배포까지 트리거합니다. 검토 없이 바로 병합되므로, 사람이
  직접 리뷰해야 하는 변경이라면 이 워크플로를 끄거나 브랜치 보호 규칙을 추가해야 합니다.

## 주요 기능

- **탭**: 상단바 바로 아래 탭 바에서 한 창에 여러 지도를 열어두고 자유롭게 오갈 수 있음.
  탭마다 실행 취소 이력과 화면 확대/이동 위치가 독립적으로 유지되고, 모든 탭은 자동으로
  저장되어 새로고침해도 그대로 남아 있음. **새 탭** 버튼(옛 "새로 만들기")은 현재 지도를
  지우지 않고 빈 지도를 새 탭으로 열고, **불러오기**로 JSON을 가져오면 현재 탭을 덮어쓰지
  않고 새 탭에 열림. 탭의 `×`를 누르면 닫히는데(마지막 탭을 닫으면 자동으로 빈 탭이 새로
  열려 항상 탭이 하나 이상 유지됨), 내용이 있는 탭을 닫을 때는 확인을 한 번 거침. 탭을
  더블클릭하면 그 자리에서 바로 이름을 지을 수 있고(상단 제목 입력창과 같은 값이라 서로
  동기화됨), 이렇게 기본값("새 시스템 지도")에서 이름을 바꿔두면 내보내기 파일명도 그
  이름을 최우선으로 사용함. 탭 라벨의 ⧉ 버튼(탭 복제)을 누르면 그 탭의 내용(노드·연결선·
  제목·화면 확대/이동 위치)을 그대로 복사한 새 탭이 바로 옆에 열리고 그리로 전환됨 — 원본과
  사본은 노드·연결선 id가 완전히 분리돼 있어 한쪽을 편집해도 다른 쪽엔 영향이 없고, 실행
  취소 이력은 새 탭 것으로 새로 시작함(원본의 되돌리기 이력까지 옮기지는 않음)
- **도형 추가**: 사각형·원·마름모 노드로 서버, 클라이언트, DB, 분기 등 시스템 구성 요소 표현
- **텍스트 노드**: 테두리 없이 글자만 있는 노드 — 인과 지도(causal loop diagram)의 변수명 표기에 적합
- **루프 라벨**: R1, B7처럼 강화(R ↻)/균형(B ↺) 순환고리를 표시하는 라벨. 속성 패널에서 유형 전환 가능
- **말풍선 노드**: 곁가지 설명·주석을 담는 회색 타원 노드
- **연결선**: 노드끼리 이어 데이터 흐름/인과 관계 표시 (실선·파선, 단방향·양방향 화살표)
- **곡선 연결선**: 연결선을 선택하면 가운데 손잡이가 나타나고, 드래그하면 인과 지도처럼 부드러운 곡선으로 휘어짐. 같은 두 노드 사이에 곡률이 다른 연결선이 여러 개 있어도 접점이 한 점에서 겹치지 않고 자연스럽게 벌어짐
- **말풍선 꼬리**: 연결선을 화살표 대신 점점 커지는 점들로 잇는 스타일 — 말풍선 노드에 설명을 붙일 때 사용
- **극성·지연 표시**: 연결선 속성에서 `+`/`-` 극성 기호와 지연(‖) 표시를 켤 수 있음 — 인과 지도 표준 표기법
- **레이블 편집**: 노드/연결선을 더블클릭하면 바로 이름을 수정 (텍스트·루프·말풍선 노드는 배치 즉시 편집 모드로 진입)
- **긴 글자 자동 줄바꿈**: 노드 이름이 길어 폭을 넘으면 옆으로 삐져나오는 대신 자동으로 두 줄 이상으로
  나뉘어 표시됨. 사각형/원/마름모/말풍선은 필요할 때만 폭·높이를 적당히 키우고(직접 크기를 늘려둔
  경우엔 그 크기를 존중), 배경이 없는 텍스트·루프 노드는 일정 폭을 넘으면 줄바꿈해 옆으로 무한정
  길어지지 않음. 사각형 등은 손잡이로 폭을 직접 조절하면 그 폭에 맞춰 줄 수가 실시간으로 다시 계산됨.
  텍스트·루프 노드도 선택하면 오른쪽 가장자리에 폭 전용 손잡이(세로 막대, ↔ 커서)가 나타나 폭을
  직접 늘리거나 줄일 수 있음 — 높이는 그 폭 안에서 줄바꿈된 결과에 맞춰 자동으로 정해짐. 한 번
  폭을 직접 조절하면 그 폭이 유지되고(가운데가 아니라 왼쪽 가장자리 고정), 이후 이름을 다시 바꿔도
  폭은 그대로인 채 줄바꿈·높이만 다시 계산됨 (모양을 다른 도형으로 바꿨다가 다시 텍스트·루프로
  바꾸면 폭 고정은 풀리고 글자에 맞춰 다시 자동 계산됨)
- **모양 전환**: 속성 패널에서 노드 모양을 사각형↔원↔마름모↔텍스트↔루프 라벨↔말풍선 사이에서 자유롭게 변경
- **빠른 확장**: 노드를 선택하고 `Insert` 키를 누르면 같은 모양의 노드가 화살표로 연결되어 오른쪽에 추가됨 — "이 다음엔 뭐가 일어나지?" 하고 결과를 이어 그릴 때 사용 (연속으로 누르면 체인처럼 이어 그릴 수 있음). `Ctrl+Insert`는 반대 방향으로, 선택한 노드의 **원인**이 되는 새 노드를 왼쪽에 추가하고 그 노드→선택한 노드로 화살표를 그음 — "이 결과를 낳은 원인이 뭐지?" 하고 거꾸로 추적해 올라갈 때 사용 (같은 노드에서 여러 번 누르면 원인 노드가 겹치지 않게 쌓임). `Shift+Insert`는 새 노드를 만들지 않고, 선택한 노드에서 자기 자신으로 돌아오는 자기 참조(self-loop) 연결선만 추가함 — 스스로를 강화·제약하는 변수를 표기할 때 사용 (노드 위쪽에 작은 고리로 그려지고, 다른 연결선처럼 가운데 손잡이를 드래그해 고리 크기를 조절할 수 있음. 같은 노드에 여러 번 누르면 겹치지 않게 고리가 조금씩 더 커짐)
- **방향키 이동**: 요소가 여러 개일 때 방향키(`←↑↓→`)로 가장 가까운 요소로 선택을 옮겨 다닐 수 있음 (화면 밖에 있으면 자동으로 스크롤)
- **속성 패널**: 선택한 요소의 이름, 모양, 색상, 화살표 방향, 극성·지연 표시를 오른쪽 패널에서 조정.
  노드는 글자 색·글자 크기를 도형 종류와 상관없이 모두 바꿀 수 있고(텍스트·루프 노드는 글자
  크기에 맞춰 박스 크기도 자동으로 다시 계산됨), 연결선도 선 색을 따로 지정할 수 있어 화살촉·
  극성 기호·지연 표시·말풍선 꼬리까지 지정한 색으로 함께 바뀜
- **다중 선택·일괄 편집**: `Shift+클릭`으로 요소를 하나씩 추가·제거하거나 `Shift+드래그`로 영역을
  지정해 여러 노드·연결선을 한꺼번에 선택. `Ctrl+A`를 누르면 캔버스의 모든 노드를 한 번에 선택함
  (노드가 하나뿐이면 일반 단일 선택으로, 없으면 아무 일도 일어나지 않음). 선택된 노드를 드래그하면
  다같이 이동하고, 색상 일괄 변경·일괄 삭제도 가능 (예: 시스템 원형 템플릿을 삽입한 뒤 통째로
  옮기거나 색을 바꿀 때 유용)
- **복사·붙여넣기**: 노드(하나 또는 여러 개)를 선택하고 `Ctrl+C`로 복사, `Ctrl+V`로 붙여넣기
  (Mac은 `Cmd`). 여러 노드를 함께 복사하면 그 노드끼리 이어진 연결선도 같이 복사되고, 붙여넣은
  사본은 원본과 조금 어긋난 위치에 생겨 바로 골라 옮길 수 있음. 같은 내용을 연달아 여러 번
  붙여넣으면(`Ctrl+V`를 반복) 점점 더 벌어지게 대각선으로 쌓이고, 탭을 옮겨도 클립보드 내용이
  그대로 남아 있어 다른 탭에도 붙여넣을 수 있음. 도구 단축키 `C`(연결)·`V`(선택)는 `Ctrl` 없이
  누를 때만 동작하므로 서로 겹치지 않음
- **정렬·배치**: 노드를 2개 이상 선택하면 속성 패널에 왼쪽/오른쪽/위/아래/가로 중앙/세로 중앙
  맞춤 버튼이 나타나 한 번에 줄을 맞출 수 있고, 3개 이상이면 가로·세로 균등 배치 버튼도 함께
  나타나 정렬된 순서를 그대로 유지하면서 노드 사이 간격을 동일하게 만들 수 있음
- **그룹화**: 노드를 2개 이상 선택하고 "그룹으로 묶기"를 누르면 영구적인 그룹이 되어, 이후로는
  Shift 없이 그룹 멤버 아무 하나만 클릭해도 전체가 함께 선택됨 (드래그하면 통째로 이동). 선택된
  그룹 주위에는 점선 테두리가 표시되어 어디까지가 한 그룹인지 한눈에 알 수 있고, 화면 캡처·SVG·
  PNG 내보내기에는 포함되지 않음. "그룹 해제" 버튼으로 다시 개별 노드로 되돌릴 수 있고, 그룹
  멤버가 삭제되어 1개만 남으면 자동으로 그룹이 풀림
- **고리 만들기(순환 구조)**: 한 방향으로 이어진 노드 2개 이상을 선택하고 속성 패널의
  "고리 만들기" 버튼(단축키 `Ctrl+Shift+L`)을 누르면 맨 끝 노드에서 맨 앞 노드로 연결선을
  새로 만들어 순환 구조로 닫아줌. 노드가 2개면 두 연결선이 서로 반대쪽으로 휘어 렌즈(원)
  모양이 되고, 3개 이상이면 노드들을 원 둘레에 고르게 재배치하고 모든 연결선을 바깥쪽으로
  둥글게 휘게 해 전체가 고리 모양으로 보이도록 만듦 (연결 순서를 알 수 있으면 그 순서를,
  모호하면 화면 위치 순서를 따름). 양방향으로 이어진 구간은 두 연결선이 서로 다른 곡률로
  갈라져 겹치지 않음
- **PT 모드**: 상단바의 "🎯 PT 모드" 버튼을 누르면 켜지는 발표용 강조 모드. 켜진 동안 노드를
  클릭하면 그 노드가 파랗게 빛나며 강조되고, 그 노드에서 **나가는**(from) 연결선만 깜박여
  "이 변수가 무엇에 영향을 주는지"를 눈에 띄게 보여줌. 같은 노드를 다시 더블클릭하면 연결선으로
  이어진 이웃 노드(들어오는·나가는 방향 모두)도 옅게 강조돼 인과 사슬을 하나씩 따라가며 설명하기
  좋음. 다른 노드를 클릭하면 강조가 그쪽으로 옮겨가고, 버튼을 다시 눌러 끄면 강조·깜박임이 모두
  사라짐 — 강조 표시 자체는 화면 연출일 뿐이라 SVG/PNG로 내보내거나 실행취소 이력에는 남지 않음.
  켜져 있는 동안은 왼쪽 도구 모음이 사라져 캔버스가 넓어지고, 노드·연결선을 클릭해도 오른쪽
  속성 패널이나 크기 조절·곡률 손잡이가 뜨지 않아(강조만 될 뿐 편집 UI는 나타나지 않음) 발표
  화면이 깔끔하게 유지됨. 노드 이동 등 드래그 조작 자체는 PT 모드 중에도 여전히 가능함.
  버튼을 다시 누르지 않아도 `Esc` 키 한 번으로 바로 꺼지므로 발표를 빠르게 마무리할 수 있음
- **노드 태그**: 노드 속성 패널의 "태그" 필드에서 태그를 입력하고 Enter로 추가, 알약(pill) 옆의
  ×로 삭제할 수 있음. 태그는 평소 캔버스에는 전혀 보이지 않다가, 그 노드를 선택했을 때만 노드
  위쪽에 작은 칩으로 나타남. 이 칩 중 하나를 누르면 같은 태그를 가진 다른 모든 노드(선택 여부와
  무관하게 캔버스 전체)가 호박색으로 함께 강조되어, "이 태그가 붙은 요소가 또 어디 있지?"를 한눈에
  찾을 수 있음 — 같은 칩을 다시 누르면 강조가 풀림. 태그·강조 표시는 SVG/PNG 내보내기에는 포함되지
  않음
- **화면 이동/확대축소**: 빈 캔버스를 드래그해 이동, 마우스 휠로 확대/축소, 화면 맞춤 버튼 제공.
  모바일에서는 두 손가락으로 오므리고 벌려 확대/축소할 수 있고, 두 손가락 사이 중심점을
  기준으로 확대되어 화면이 함께 이동하는 느낌 없이 자연스럽게 커지고 작아짐
- **선택 해제**: 노드·연결선을 선택한 뒤 빈 캔버스를 누르면 선택이 풀림. 속성 패널 안의
  빈 여백(입력칸·버튼이 아닌 곳)을 눌러도 마찬가지로 선택이 풀리는데, 모바일에서는 패널이
  캔버스 대부분을 가려 빈 캔버스를 직접 누르기 어렵기 때문에 유용함 (단, 캔버스에서 시작한
  드래그가 패널 밑에서 끝나는 경우는 실수로 풀리지 않도록 구분함)
- **실행 취소/다시 실행**: `Ctrl+Z` / `Ctrl+Shift+Z`
- **자동 저장**: 열려 있는 모든 탭이 브라우저 `localStorage`에 자동 저장되어 새로고침해도 유지
- **내보내기/불러오기**: JSON(재편집용), SVG·PNG(공유·삽입용) 파일로 내보내고, JSON 파일을 다시 불러오기.
  지원하는 브라우저(Chrome·Edge 등)에서는 내보내기 시 저장 위치·파일명을 직접 고를 수 있는
  파일 대화상자가 열리고(취소하면 아무 일도 일어나지 않음), 지원하지 않는 브라우저에서는
  기존처럼 다운로드 폴더로 바로 저장됨. 기본 파일명은 탭 이름을 기본값에서 직접 바꿔뒀다면
  그 이름을 최우선으로 쓰고, 아직 이름을 정하지 않았다면 사각형 노드가 정확히 하나만 있을
  때 그 노드의 텍스트를, 그 외에는 지도 제목(기본값)을 사용
- **다크 모드**: 우측 상단 버튼으로 라이트/다크 테마 전환
- **모바일 최적화**: 좁은 화면에서는 상단바가 두 줄로 접히고, 속성 패널이 화면을 다 가리지 않는
  너비로 오버레이 표시되며, 하단 안내 문구는 잘려서 한 줄로 유지됩니다. 도형 도구를 탭하면
  두 번째 탭 없이 바로 화면 가운데에 노드가 놓이고 확대/축소 배율도 100%로 초기화되어,
  작은 화면에서 정확한 위치를 두 번 짚기 어려운 문제를 피합니다 (놓은 뒤 손가락으로 끌어 옮기면 됨).
  "시스템 원형"·"내보내기" 드롭다운은 버튼 위치를 기준으로 화면 밖으로 잘리지 않도록 매번
  뷰포트 안쪽으로 다시 계산해 열리므로, 버튼이 상단바 중간에 있어도 메뉴 전체가 항상 보입니다
- **시스템 원형(archetype) 템플릿**: 상단 "시스템 원형" 메뉴에서 자주 쓰는 인과 지도 패턴을
  원클릭으로 삽입할 수 있습니다. 그래프 모양을 하나씩 다시 다듬는 중이라 아직
  **"성장의 한계"**, **"역효과를 낳는 해결책"**, **"부담 떠넘기기"**, **"성공한 쪽에
  몰아주기"** 네 가지만 실제로 그려본 참고 지도를 바탕으로 노드 배치와 곡률까지 다듬어
  구현 완료했고, 나머지 항목은 목록에 보이되
  "구현중" 배지가 붙은 채 비활성 상태입니다 (준비되는 대로 `ARCHETYPE_TEMPLATES`의
  해당 항목을 `implemented: true`로 바꾸면 활성화됩니다).
- **문장으로 그리기**: 상단 "문장으로 그리기" 버튼을 누르면 인과 관계 문장을 입력해 자동으로
  다이어그램을 만드는 창이 열립니다. 한 줄에 문장을 하나씩(여러 줄 입력 가능) 적으면 되고,
  같은 이름이 여러 문장에 반복되면 하나의 노드로 합쳐져 서로 이어집니다. 지원 형식은 세 가지:
  **"A가 증가하면 B도 증가/감소한다"**(인과 관계에 극성 `+`/`-`까지 자동으로 붙음),
  **"A 때문에 B"** / **"A → B"**(단순 인과, 극성 없음), **"A → B → C → D"**(화살표를 2개 이상
  이어 쓰면 각 구간이 A→B, B→C, C→D로 나뉘어 한 줄에 연쇄 흐름 전체를 한 번에 그릴 수 있음).
  연쇄 화살표의 마지막 구간을 맨 처음 노드와 같은 이름으로 쓰거나 **"(처음)"**/**"(처음으로)"**로
  쓰면 순환 고리로 인식해 새 노드를 만드는 대신 첫 노드로 다시 연결하고, "고리 만들기" 기능과
  같은 방식으로 원형으로 배치함 (예: "시간 부족 → IT교육 참여 저조 → 디지털 역량 정체 →
  업무 효율 개선 안됨 → (처음)"). 서버 없이 브라우저 안에서 정규식으로
  처리하는 규칙 기반 파서라, 정해진 문형에서 벗어난 자유로운 문장은 인식하지 못하고 건너뛰며
  (건너뛴 문장은 만들고 나서 알려줌), 100% 정확하진 않습니다 — 특히 "도"로 끝나는 단어(예:
  "인지도")는 "~도 증가한다"의 조사 "도"와 구별하지 못해 잘못 잘릴 수 있습니다.

### 시스템 사고(인과 지도) 그리기

강화/균형 루프가 있는 시스템 다이내믹스 다이어그램은 **시스템 원형** 메뉴에서 구현된
원형을 원클릭 삽입하거나, 다음 조합으로 직접 그릴 수 있습니다.

1. **텍스트** 도구로 변수명(예: "취약 계층의 건강")을 테두리 없이 배치
2. **연결** 도구로 원인 → 결과 방향에 화살표를 긋고, 필요하면 손잡이를 드래그해 곡선으로 조정
3. 연결선 속성 패널에서 **극성**(`+`/`-`)과 **지연 표시**(‖)를 필요한 곳에 설정
4. **루프** 도구로 순환고리 중앙에 "R1", "B2" 같은 라벨을 놓고 강화/균형 유형을 선택
5. 외부에서 참조되는 변수(다른 페이지에서도 등장하는 변수 등)는 **사각형** 노드로 박스를 둘러 구분
6. 곁가지 설명이나 근거는 **말풍선** 도구로 추가하고, 관련 변수와 **말풍선 꼬리** 스타일 연결선으로 이어 화살표 없이 점점 커지는 점들로 연결

## 단축키

| 키 | 동작 |
| --- | --- |
| `V` | 선택 도구 |
| `R` / `O` / `D` | 사각형 / 원 / 마름모 노드 추가 도구 |
| `T` / `L` / `B` | 텍스트 노드 / 루프 라벨 / 말풍선 추가 도구 |
| `C` | 연결선 도구 |
| `Shift+클릭` | 요소를 다중 선택 목록에 추가·제거 |
| `Shift+드래그` | 영역(마퀴)을 지정해 여러 노드를 한꺼번에 선택 |
| `Ctrl+A` | 캔버스의 모든 노드 선택 (노드가 없으면 아무 동작 안 함) |
| `Ctrl+C` / `Ctrl+V` | 선택한 노드(들) 복사 / 붙여넣기 (탭을 옮겨도 유지됨) |
| `Insert` | 선택한 노드의 결과가 되는 새 노드를 오른쪽에 추가하고 화살표로 연결 (연속으로 누르면 체인처럼 이어짐) |
| `Ctrl+Insert` | 선택한 노드의 원인이 되는 새 노드를 왼쪽에 추가하고 그 노드 → 선택한 노드로 연결 |
| `Shift+Insert` | 새 노드 없이, 선택한 노드에서 자기 자신으로 돌아오는 자기 참조 연결선만 추가 |
| `←` `↑` `↓` `→` | 방향에 있는 가장 가까운 요소로 선택 이동 |
| `F2` | 선택한 노드·연결선의 텍스트를 바로 편집 (더블클릭과 동일) |
| `Ctrl+G` | 선택한 노드 2개 이상을 그룹으로 묶기 · 이미 그룹이면 해제 (토글) |
| `Ctrl+Shift+L` | 선택한 노드 2개 이상을 순환 구조(고리)로 닫기 |
| `Delete` / `Backspace` | 선택한 요소 삭제 |
| `Ctrl+Z` / `Ctrl+Shift+Z` | 실행 취소 / 다시 실행 |
| `+` / `-` / `0` | 확대 / 축소 / 화면 맞춤 |
| `Esc` | 선택 해제·연결 취소 (PT 모드 중이면 PT 모드도 함께 꺼짐) |

## 기술 스택

순수 HTML/CSS/JavaScript(바닐라, 빌드 도구 불필요)로 작성된 SVG 기반 다이어그램
에디터입니다. 외부 라이브러리나 백엔드 서버 없이 정적 파일만으로 동작하므로 GitHub
Pages, Netlify, Vercel 등 어떤 정적 호스팅에도 그대로 배포할 수 있습니다.

```
index.html      메인 페이지
css/style.css   스타일 (라이트/다크 테마)
js/app.js       다이어그램 에디터 로직
```
