# 🗺️ SysMap — 시스템 지도 그리기

브라우저에서 바로 시스템 아키텍처 다이어그램은 물론, 강화·균형 루프가 있는
**인과 지도(causal loop diagram, 시스템 사고 지도)**까지 그릴 수 있는 온라인 도구입니다.
설치나 로그인 없이 정적 웹페이지만으로 동작하며, 그린 지도는 브라우저에 자동 저장되고
JSON/SVG/PNG 파일로 내보내거나 다시 불러올 수 있습니다.

## 사용해보기

- **로컬에서 열기**: `index.html`을 브라우저로 열면 바로 사용할 수 있습니다.
  (더블클릭으로 열거나, 정적 서버로 띄우려면 `python3 -m http.server` 등을 사용하세요.)
- **온라인으로 배포하기**: 이 저장소를 GitHub Pages로 배포하면 별도 서버 없이 URL 하나로
  누구나 접속해 지도를 그릴 수 있습니다. `.github/workflows/deploy.yml` 워크플로가 `main`
  브랜치에 푸시될 때마다 자동으로 GitHub Pages에 배포합니다.
  (저장소 Settings → Pages → Source를 "GitHub Actions"로 설정하면 활성화됩니다.)

## 주요 기능

- **도형 추가**: 사각형·원·마름모 노드로 서버, 클라이언트, DB, 분기 등 시스템 구성 요소 표현
- **텍스트 노드**: 테두리 없이 글자만 있는 노드 — 인과 지도(causal loop diagram)의 변수명 표기에 적합
- **루프 라벨**: R1, B7처럼 강화(R ↻)/균형(B ↺) 순환고리를 표시하는 라벨. 속성 패널에서 유형 전환 가능
- **말풍선 노드**: 곁가지 설명·주석을 담는 회색 타원 노드
- **연결선**: 노드끼리 이어 데이터 흐름/인과 관계 표시 (실선·파선, 단방향·양방향 화살표)
- **곡선 연결선**: 연결선을 선택하면 가운데 손잡이가 나타나고, 드래그하면 인과 지도처럼 부드러운 곡선으로 휘어짐. 같은 두 노드 사이에 곡률이 다른 연결선이 여러 개 있어도 접점이 한 점에서 겹치지 않고 자연스럽게 벌어짐
- **말풍선 꼬리**: 연결선을 화살표 대신 점점 커지는 점들로 잇는 스타일 — 말풍선 노드에 설명을 붙일 때 사용
- **극성·지연 표시**: 연결선 속성에서 `+`/`-` 극성 기호와 지연(‖) 표시를 켤 수 있음 — 인과 지도 표준 표기법
- **레이블 편집**: 노드/연결선을 더블클릭하면 바로 이름을 수정 (텍스트·루프·말풍선 노드는 배치 즉시 편집 모드로 진입)
- **모양 전환**: 속성 패널에서 노드 모양을 사각형↔원↔마름모↔텍스트↔루프 라벨↔말풍선 사이에서 자유롭게 변경
- **빠른 확장**: 노드를 선택하고 `Insert` 키를 누르면 같은 모양의 노드가 화살표로 연결되어 추가됨 (연속으로 누르면 체인처럼 이어 그릴 수 있음)
- **방향키 이동**: 요소가 여러 개일 때 방향키(`←↑↓→`)로 가장 가까운 요소로 선택을 옮겨 다닐 수 있음 (화면 밖에 있으면 자동으로 스크롤)
- **속성 패널**: 선택한 요소의 이름, 모양, 색상, 화살표 방향, 극성·지연 표시를 오른쪽 패널에서 조정
- **화면 이동/확대축소**: 빈 캔버스를 드래그해 이동, 마우스 휠로 확대/축소, 화면 맞춤 버튼 제공
- **실행 취소/다시 실행**: `Ctrl+Z` / `Ctrl+Shift+Z`
- **자동 저장**: 브라우저 `localStorage`에 자동 저장되어 새로고침해도 유지
- **내보내기/불러오기**: JSON(재편집용), SVG·PNG(공유·삽입용) 파일로 내보내고, JSON 파일을 다시 불러오기
- **다크 모드**: 우측 상단 버튼으로 라이트/다크 테마 전환
- **시스템 원형(archetype) 템플릿**: 상단 "시스템 원형" 메뉴에서 자주 쓰는 인과 지도 패턴을
  원클릭으로 삽입 — 노드·연결선·곡률·지연/극성 표시·루프 라벨까지 완성된 구조로 바로 배치되고,
  라벨만 상황에 맞게 고치면 됨. 이미 있는 지도 위에 삽입해도 겹치지 않게 빈 자리를 찾아 배치

### 시스템 원형(archetype) 템플릿 목록

"시스템 원형" 메뉴에서 아래 7가지를 한 번에 삽입할 수 있습니다.

| 이름 | 설명 |
| --- | --- |
| 선순환/악순환 (강화 루프) | 두 요인이 서로를 증폭시키는 가장 기본적인 R 루프 |
| 균형 프로세스 | 목표와의 격차를 줄이려는 조정 행동이 반복되는 B 루프 |
| 역효과를 낳는 해결책 | 임시방편이 지연을 두고 문제를 다시 악화시키는 구조 (B1/R2) |
| 부담 떠넘기기 | 임시방편의 부작용이 장기적 해결책을 약화시키는 구조 (B1/B2/R3) |
| 성장의 한계 | 성장을 이끄는 행동이 결국 제약 요인에 부딪히는 구조 (R1/B2) |
| 성공한 쪽에 몰아주기 | 한쪽에 자원이 쏠릴수록 다른 쪽의 기회가 줄어드는 구조 (R1/R2) |
| 뜻하지 않은 적수 | 선의의 협력이 서로 모르는 사이 적대적으로 변하는 구조 (R1/B2/R4/B3) |

### 시스템 사고(인과 지도) 그리기

강화/균형 루프가 있는 시스템 다이내믹스 다이어그램은 다음 조합으로 그릴 수 있습니다.
(자주 나오는 구조라면 처음부터 그리는 대신 위의 **시스템 원형 템플릿**을 삽입해 시작하는 편이 빠릅니다.)

1. **텍스트** 도구로 변수명(예: "취약 계층의 건강")을 테두리 없이 배치
2. **연결** 도구로 원인 → 결과 방향에 화살표를 긋고, 필요하면 손잡이를 드래그해 곡선으로 조정
3. 연결선 속성 패널에서 **극성**(`+`/`-`)과 **지연 표시**(‖)를 필요한 곳에 설정
4. **루프** 도구로 순환고리 중앙에 "R1", "B2" 같은 라벨을 놓고 강화/균형 유형을 선택
5. 외부에서 참조되는 변수(다른 페이지에서도 등장하는 변수 등)는 **사각형** 노드로 박스를 둘러 구분
6. 곁가지 설명이나 근거는 **말풍선** 도구로 추가하고, 관련 변수와 **말풍선 꼬리** 스타일 연결선으로 이어 화살표 없이 점점 커지는 점들로 연결

## 단축키

| 키 | 동작 |
| --- | --- |
| `V` | 선택 도구 |
| `R` / `O` / `D` | 사각형 / 원 / 마름모 노드 추가 도구 |
| `T` / `L` / `B` | 텍스트 노드 / 루프 라벨 / 말풍선 추가 도구 |
| `C` | 연결선 도구 |
| `Insert` | 선택한 노드와 같은 모양의 노드를 추가하고 화살표로 연결 (연속으로 누르면 체인처럼 이어짐) |
| `←` `↑` `↓` `→` | 방향에 있는 가장 가까운 요소로 선택 이동 |
| `Delete` / `Backspace` | 선택한 요소 삭제 |
| `Ctrl+Z` / `Ctrl+Shift+Z` | 실행 취소 / 다시 실행 |
| `+` / `-` / `0` | 확대 / 축소 / 화면 맞춤 |
| `Esc` | 선택 해제·연결 취소 |

## 기술 스택

순수 HTML/CSS/JavaScript(바닐라, 빌드 도구 불필요)로 작성된 SVG 기반 다이어그램
에디터입니다. 외부 라이브러리나 백엔드 서버 없이 정적 파일만으로 동작하므로 GitHub
Pages, Netlify, Vercel 등 어떤 정적 호스팅에도 그대로 배포할 수 있습니다.

```
index.html      메인 페이지
css/style.css   스타일 (라이트/다크 테마)
js/app.js       다이어그램 에디터 로직
```
